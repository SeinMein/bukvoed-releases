# Буквоед для Windows

[Скачать Bukvoed.exe](https://raw.githubusercontent.com/SeinMein/bukvoed-releases/main/Bukvoed.exe)

Положите EXE в отдельную папку и запустите его. При первом запуске он скачает приложение с начальным словарём. При следующих запусках он проверит выпуск и скачает изменившиеся файлы приложения. Для скачивания нужен интернет. Учётная запись GitHub и установленный Git не нужны.

Каждый компьютер хранит собственный банк слов и исключения в папке запуска. Обновления приложения сохраняют эти файлы. Условия и источники начального словаря указаны в [WORD-BANK-LICENSE.txt](app/_internal/WORD-BANK-LICENSE.txt) и [LEXICON-LICENSE.txt](app/_internal/LEXICON-LICENSE.txt).

Версия 2026.11.10.3 (v17): исправлены запуск перезапуска сразу из лобби и отправка движения/прыжка. Перед отходом бот снимает фокус с поля ввода; W/A/S/D/Space отправляются как клавиши управления только во время перезапуска. Проверено на живой игре: прыжок, отход, возврат к стулу, экран «Ждём второго игрока». Для обновления закройте приложение и снова запустите Bukvoed.exe.

Код исправления, воспроизводимая сборка и результаты проверок: [maintenance/README.md](maintenance/README.md).
