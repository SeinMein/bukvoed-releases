# Буквоед для Windows

[Скачать Bukvoed.exe](https://raw.githubusercontent.com/SeinMein/bukvoed-releases/main/Bukvoed.exe)

Положите EXE в отдельную папку и запустите его. При первом запуске он скачает приложение и общий словарь. При следующих запусках он проверит выпуск и скачает изменившиеся файлы. Для скачивания нужен интернет. Учётная запись GitHub и установленный Git не нужны.

Файлы личного банка, список выученных слов и журналы находятся в папке запуска. Общий словарь входит в выпуск. Его условия и источники указаны в [WORD-BANK-LICENSE.txt](app/_internal/WORD-BANK-LICENSE.txt) и [LEXICON-LICENSE.txt](app/_internal/LEXICON-LICENSE.txt).
