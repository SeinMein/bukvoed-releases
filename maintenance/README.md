## Повторная сборка

Нужен Python 3.13. Исходный EXE берётся из коммита 08ffd6a:

```python
import pathlib, subprocess
pathlib.Path('base.exe').write_bytes(subprocess.check_output([
    'git', 'show', '08ffd6a:app/BukvoedApp.exe'
]))
```

```text
python maintenance/release_patch.py base.exe fixed.exe
python maintenance/test_restart.py base.exe fixed.exe [папка_кадров]
python maintenance/test_chair.py base.exe fixed.exe
```

Для тестов нужны NumPy, OpenCV и Pillow под Python 3.13. Записи и кадры
с компьютера пользователя в репозиторий не включены. SHA-256 базового EXE
проверяется перед изменением; заменяется только точка входа bot в архиве
PyInstaller. Загрузчик EXE и остальные архивные элементы сохраняются.
Для сборки v16 нужна полная история этого Git-репозитория: процедура движения
берётся из указанного коммита, SHA-256 прежнего EXE проверяется до извлечения.

После замены app/BukvoedApp.exe необходимо обновить его SHA-256
в manifest.json и номер выпуска. Корневой Bukvoed.exe при следующем
запуске скачает изменившееся приложение.
